Nuances utiles à l’examen

  • CAP décrit l’arbitrage pendant une partition réseau, pas une étiquette permanente de toute base.
  • ACID, CAP et BASE parlent de propriétés différentes. MongoDB prend aussi en charge les transactions.
  • Dans le TP 3, $size:3 signifie exactement trois éléments. Pour « au moins trois », le chemin "resultats.2":{$exists:true} convient.
  • Le TP 5 classe replaceOne() avec « Delete »; c’est une opération de remplacement.
  • Le fichier produits.json présent concerne le TP 4. Le jeu de données décrit au TP 5 n’est pas fourni; les corrections suivent ses noms de champs.
