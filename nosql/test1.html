Partie 1 : requêtes de lecture (find)

Question 1

Afficher tous les joueurs.

Question 6

$all sur matchs.adversaire : le tableau des adversaires doit contenir les deux valeurs, qui peuvent venir de deux matchs différents.

Question 7

Utiliser l'opérateur $size pour afficher les joueurs ayant exactement trois matchs enregistrés.

Réponse

Question 8

Utiliser l'opérateur $elemMatch pour afficher les joueurs ayant obtenu une note supérieure ou égale à 8 dans un match où ils ont marqué au moins un but.

Réponse
db.joueurs.find({ matchs: { $elemMatch: { note: { $gte: 8 }, buts: { $gte: 1 } } } }, { nom: 1, _id: 0 })

Résultat sur le jeu d'essai

{"nom": "Achraf Hakimi"}
{"nom": "Kylian Mbappé"}
{"nom": "Erling Haaland"}

$elemMatch impose que les deux conditions soient vraies dans le même match. Sans lui, la note de 8 et le but pourraient venir de deux matchs différents.

Question 9

Utiliser l'opérateur $exists pour afficher les joueurs pour lesquels le champ performance.passes existe.

Réponse
db.joueurs.find({ "performance.passes": { $exists: true } }, { nom: 1, _id: 0 })

Résultat sur le jeu d'essai

{"nom": "Achraf Hakimi"}
{"nom": "Kylian Mbappé"}
{"nom": "Sofyan Amrabat"}
{"nom": "Erling Haaland"}

$exists: true garde les documents où le champ existe, même s'il vaut 0. Le joueur d'exemple d'Al-Hilal n'a pas de passes : il est exclu.

Question 10

Combiner $all et $elemMatch pour afficher les joueurs ayant affronté « Marseille » et « Lens » et ayant obtenu une note supérieure ou égale à 8 dans au moins un de ces matchs.

Réponse
db.joueurs.find({
  matchs: {
    $all: [
      { $elemMatch: { adversaire: "Marseille" } },
      { $elemMatch: { adversaire: "Lens" } }
    ],
    $elemMatch: { adversaire: { $in: ["Marseille", "Lens"] }, note: { $gte: 8 } }
  }
}, { nom: 1, _id: 0 })

Résultat sur le jeu d'essai

{"nom": "Achraf Hakimi"}
{"nom": "Kylian Mbappé"}

$all avec deux $elemMatch exige les deux adversaires. Le second $elemMatch exige, dans un match contre Marseille ou Lens, une note d'au moins 8. Si l'énoncé voulait 8 dans les deux matchs, il faudrait deux $elemMatch avec note chacun.

Question 11

Combiner $in et $elemMatch pour afficher les joueurs dont la nationalité est parmi [« Maroc », « France »] et ayant obtenu une note supérieure ou égale à 8.5 dans un match.

Réponse
db.joueurs.find({
  nationalite: { $in: ["Maroc", "France"] },
  matchs: { $elemMatch: { note: { $gte: 8.5 } } }
}, { nom: 1, _id: 0 })

Résultat sur le jeu d'essai

{"nom": "Kylian Mbappé"}

Deux conditions sur deux champs différents : elles se combinent avec un ET implicite dans le même document de filtre.

Question 13

Afficher uniquement les deux premiers joueurs après avoir ignoré le premier dans la liste triée par âge croissant. (pensez à utiliser sort, skip et limit)

Réponse
db.joueurs.find({}, { nom: 1, age: 1, _id: 0 }).sort({ age: 1 }).skip(1).limit(2)

Partie 2 : pipeline d'agrégation ($project)

Question 1

Afficher le nom du joueur et uniquement les matchs dont la note est supérieure ou égale à 8. (pensez à utiliser $filter)

Réponse
db.joueurs.aggregate([
  { $project: {
      _id: 0,
      nom: 1,
      matchs: { $filter: { input: "$matchs", as: "m", cond: { $gte: ["$$m.note", 8] } } }
  } }
])

Résultat sur le jeu d'essai

{"nom": "Achraf Hakimi", "matchs": [{"adversaire": "Marseille", "competition": "Ligue 1", "buts": 1, "passes": 1, "note": 8.2}]}
{"nom": "Kylian Mbappé", "matchs": [{"adversaire": "Marseille", "competition": "Ligue 1", "buts": 2, "passes": 0, "note": 9.1}, {"adversaire": "Lens", "competition": "Ligue 1", "buts": 1, "passes": 1, "note": 8.7}, {"adversaire": "Newcastle", "competition": "Ligue des Champions", "buts": 1, "passes": 1, "note": 9}]}
{"nom": "Sofyan Amrabat", "matchs": []}
{"nom": "Erling Haaland", "matchs": [{"adversaire": "Liverpool", "competition": "Premier League", "buts": 2, "passes": 0, "note": 9}, {"adversaire": "Arsenal", "competition": "Premier League", "buts": 1, "passes": 0, "note": 8.5}]}
{"nom": "Joueur Al-Hilal (exemple)", "matchs": []}

$filter garde dans un tableau les éléments qui vérifient cond. as: "m" nomme l'élément courant, qu'on lit avec $$m (deux dollars). Un joueur sans match valide a un tableau vide (Amrabat, Al-Hilal).

Question 5

        }
      }
  } }
])

Résultat sur le jeu d'essai

On filtre d'abord, puis on applique $map au résultat : input du $map est le $filter.

db.joueurs.updateOne({ nom: "Achraf Hakimi" }, { $set: { age: 26 } })

updateOne modifie un seul document (le premier qui correspond). $set remplace la valeur du champ.

Augmenter le nombre de minutes jouées de tous les joueurs du club « Paris Saint-Germain » de 100 minutes. (pensez à utiliser updateMany() avec $inc)

Réponse
db.joueurs.updateMany({ club: "Paris Saint-Germain" }, { $inc: { "performance.minutes_jouees": 100 } })

Résultat sur le jeu d'essai

matchedCount : 2, modifiedCount : 2
// vérification
db.joueurs.find({ club: "Paris Saint-Germain" }, { nom: 1, "performance.minutes_jouees": 1, _id: 0 })
{"nom": "Achraf Hakimi", "performance": {"minutes_jouees": 2900}}
{"nom": "Kylian Mbappé", "performance": {"minutes_jouees": 2800}}

Notation pointée pour un champ du sous-document : performance.minutes_jouees. updateMany modifie tous les joueurs du club (2 ici).

Question 3

Supprimer le champ minutes_jouees pour tous les joueurs du club « Al-Hilal ». (pensez à utiliser $unset)

Réponse
db.joueurs.updateMany({ club: "Al-Hilal" }, { $unset: { "performance.minutes_jouees": "" } })

Résultat sur le jeu d'essai

matchedCount : 1, modifiedCount : 1
// vérification
db.joueurs.find({ club: "Al-Hilal" }, { nom: 1, performance: 1, _id: 0 })
{"nom": "Joueur Al-Hilal (exemple)", "performance": {"saison": "2023/2024", "buts": 10}}

$unset supprime le champ ; la valeur donnée ("") est ignorée.

Question 4

Renommer le champ nationalite en pays pour tous les documents. (pensez à utiliser $rename)

Réponse
db.joueurs.updateMany({}, { $rename: { nationalite: "pays" } })

Résultat sur le jeu d'essai

matchedCount : 5, modifiedCount : 5
// vérification
db.joueurs.find({}, { nom: 1, pays: 1, nationalite: 1, _id: 0 })
{"nom": "Achraf Hakimi", "pays": "Maroc"}
{"nom": "Kylian Mbappé", "pays": "France"}
{"nom": "Sofyan Amrabat", "pays": "Maroc"}
{"nom": "Erling Haaland", "pays": "Norvège"}
{"nom": "Joueur Al-Hilal (exemple)", "pays": "Arabie saoudite"}

Pour viser tous les documents, le filtre est {}. $rename : { ancien: "nouveau" }.

Question 5

Ajouter un nouveau match au joueur « Erling Haaland » avec l'adversaire « Tottenham », compétition « Premier League », buts 1, passes 1, note 8.4. (pensez à utiliser $push)

Réponse
db.joueurs.updateOne(
  { nom: "Erling Haaland" },
  { $push: { matchs: { adversaire: "Tottenham", competition: "Premier League", buts: 1, passes: 1, note: 8.4 } } }
)

Résultat sur le jeu d'essai

matchedCount : 1, modifiedCount : 1
// vérification
db.joueurs.find({ nom: "Erling Haaland" }, { nom: 1, matchs: 1, _id: 0 })
{"nom": "Erling Haaland", "matchs": [{"adversaire": "Liverpool", "competition": "Premier League", "buts": 2, "passes": 0, "note": 9}, {"adversaire": "Arsenal", "competition": "Premier League", "buts": 1, "passes": 0, "note": 8.5}, {"adversaire": "Tottenham", "competition": "Premier League", "buts": 1, "passes": 1, "note": 8.4}]}

$push ajoute l'élément à la fin du tableau, même s'il existe déjà.

Question 6

Supprimer tous les matchs du joueur « Kylian Mbappé » contre « Lens ». (pensez à utiliser $pull)

Réponse
db.joueurs.updateOne({ nom: "Kylian Mbappé" }, { $pull: { matchs: { adversaire: "Lens" } } })

Résultat sur le jeu d'essai

matchedCount : 1, modifiedCount : 1
// vérification
db.joueurs.find({ nom: "Kylian Mbappé" }, { nom: 1, "matchs.adversaire": 1, _id: 0 })
{"nom": "Kylian Mbappé", "matchs": [{"adversaire": "Marseille"}, {"adversaire": "Newcastle"}]}

$pull retire du tableau tous les éléments qui vérifient la condition (ici, les sous-documents dont l'adversaire est Lens).

Question 7

Ajouter la compétition « UEFA Super Cup » dans un tableau de compétitions d'un joueur sans créer de doublons. (pensez à utiliser $addToSet)

Réponse
db.joueurs.updateOne({ nom: "Erling Haaland" }, { $addToSet: { competitions: "UEFA Super Cup" } })

Résultat sur le jeu d'essai

matchedCount : 1, modifiedCount : 1
2e exécution : matchedCount : 1, modifiedCount : 0
// vérification
db.joueurs.find({ nom: "Erling Haaland" }, { nom: 1, competitions: 1, _id: 0 })
{"nom": "Erling Haaland", "competitions": ["UEFA Super Cup"]}

$addToSet n'ajoute que si la valeur est absente. À la deuxième exécution, modifiedCount vaut 0. Le champ competitions est créé s'il n'existe pas. L'énoncé ne dit pas quel joueur ni quel champ : j'ai pris Haaland et competitions.

Question 8

Modifier la note du match contre « Marseille » pour le joueur « Achraf Hakimi » et la passer à 9.0. (pensez à utiliser arrayFilters avec $set)

Réponse
db.joueurs.updateOne(
  { nom: "Achraf Hakimi" },
  { $set: { "matchs.$[m].note": 9.0 } },
  { arrayFilters: [{ "m.adversaire": "Marseille" }] }
)

Résultat sur le jeu d'essai

matchedCount : 1, modifiedCount : 1
// vérification
db.joueurs.find({ nom: "Achraf Hakimi" }, { nom: 1, matchs: 1, _id: 0 })
{"nom": "Achraf Hakimi", "matchs": [{"adversaire": "Marseille", "competition": "Ligue 1", "buts": 1, "passes": 1, "note": 9}, {"adversaire": "Lens", "competition": "Ligue 1", "buts": 0, "passes": 1, "note": 7.6}]}

$[m] désigne les éléments du tableau qui vérifient le filtre nommé m dans arrayFilters. Le nom (m) doit commencer par une minuscule et être le même des deux côtés.

Question 9

Modifier la note de tous les matchs où le joueur a marqué au moins 1 but, en ajoutant +0.2 à la note existante. (pensez à utiliser updateMany() avec $inc et arrayFilters)

Réponse
db.joueurs.updateMany(
  {},
  { $inc: { "matchs.$[m].note": 0.2 } },
  { arrayFilters: [{ "m.buts": { $gte: 1 } }] }
)

Résultat sur le jeu d'essai

matchedCount : 5, modifiedCount : 5
// vérification
db.joueurs.find({ nom: "Sofyan Amrabat" }, { nom: 1, matchs: 1, _id: 0 })
{"nom": "Sofyan Amrabat", "matchs": [{"adversaire": "Liverpool", "competition": "Premier League", "buts": 0, "passes": 0, "note": 7.3}, {"adversaire": "Chelsea", "competition": "Premier League", "buts": 1, "passes": 0, "note": 8.1}]}

Même principe avec $inc, sur tous les joueurs ({} et updateMany). Avec des décimaux, le résultat peut s'afficher avec beaucoup de chiffres (par exemple 9.299999999999999 pour 9.1 + 0.2) : c'est la virgule flottante, pas une erreur.

Question 10

Remplacer complètement le document du joueur « Sofyan Amrabat » par un nouveau document contenant uniquement : { nom: "Sofyan Amrabat", club: "Manchester United", nationalite: "Maroc", poste: "Milieu défensif" }. (pensez à utiliser replaceOne())

Réponse
db.joueurs.replaceOne(
  { nom: "Sofyan Amrabat" },
  { nom: "Sofyan Amrabat", club: "Manchester United", nationalite: "Maroc", poste: "Milieu défensif" }
)

Résultat sur le jeu d'essai

matchedCount : 1, modifiedCount : 1
// vérification
db.joueurs.find({ nom: "Sofyan Amrabat" })
{"_id": 3, "nom": "Sofyan Amrabat", "club": "Manchester United", "nationalite": "Maroc", "poste": "Milieu défensif"}

replaceOne remplace tout le document sauf _id : performance et matchs disparaissent. Pas d'opérateur $ dans le nouveau document.
