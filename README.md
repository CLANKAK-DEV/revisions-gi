# Révisions 4ème année Génie Informatique

Sites de révision statiques (HTML, CSS, JavaScript, sans framework), un par matière :

- `nosql/` : NoSQL et MongoDB
- `reseaux/` : Réseaux et Télécoms
- `aqql/` : Qualité logicielle
- `php/` : PHP, Technologies Web Avancées

Chaque site contient un résumé, des exercices corrigés, des QCM, des questions de cours et un examen blanc.
Ouvrez `index.html` dans un navigateur : tout fonctionne hors ligne.

Résumés et corrigés rédigés d'après les cours et TP des enseignants. Ce dépôt ne contient pas les supports de cours d'origine.
