Le module en 8 phrases

  1. Flutter est un framework de Google qui produit des applications Android, iOS, Web et Desktop avec un seul code, écrit en Dart.
  2. Dans Flutter, tout est un widget : on décrit l'interface en code, en imbriquant des widgets.
  3. Une application commence par main(), qui appelle runApp() avec un widget racine, en général MaterialApp puis Scaffold.
  4. Un Container a un seul enfant (child) ; Column et Row en ont plusieurs (children).
  5. margin est l'espace autour d'un conteneur, padding l'espace à l'intérieur.
  6. Un StatelessWidget ne change jamais ; un StatefulWidget change grâce à setState.
  7. onPressed reçoit une fonction ; validator d'un TextFormField renvoie une erreur ou null ; validate() vérifie tout le formulaire.
  8. En Dart, un type ne peut pas être null sauf avec ? ; on utilise ?., ?? et ! pour gérer le null.

La recette d'une application de test

  1. Écrire la classe de données (avec constructeur) et la liste d'exemples.
  2. Écrire main() qui appelle runApp, puis un MaterialApp avec home.
  3. Choisir Stateless ou Stateful : si quelque chose change au clic, Stateful.
  4. Construire l'écran dans l'ordre : Scaffold, appBar, body, floatingActionButton.
  5. Dans le body : Card ou Column, puis les Text, Image, Chip, Icon.
  6. Ajouter la logique : une fonction qui modifie l'état dans setState.
  7. Ajouter la validation s'il y a un formulaire.
  8. Tester : un hot reload après chaque étape. Vérifier les cas limites (champ vide, dernier élément de la liste).

Les 15 éléments à connaître par cœur

  1. Flutter : un code, Android + iOS + Web + Desktop ; langage Dart ; pas de WebView.
  2. void main() { runApp(...); } est le point d'entrée.
  3. MaterialApp(home: Scaffold(appBar: AppBar(...), body: ...)) est le squelette.
  4. Scaffold : appBar, body, floatingActionButton, drawer, bottomNavigationBar.
  5. AppBar : leading (gauche), title, actions (droite liste).
  6. child pour un enfant, children pour plusieurs.
  7. margin dehors, padding dedans ; EdgeInsets.all / only / symmetric / fromLTRB.
  8. Row : axe principal horizontal ; Column : axe principal vertical ; mainAxisAlignment et crossAxisAlignment.
  9. Les 6 mainAxisAlignment : start, end, center, spaceBetween, spaceAround, spaceEvenly.
  10. Card sans padding ; ClipOval carré = cercle ; ListTile : leading, title, subtitle, trailing.
  11. Stateless ne change pas ; Stateful : deux classes, createState(), setState.
  12. Hot reload garde l'état ; hot restart le réinitialise.
  13. Elevated (principal), Outlined (secondaire), Text (faible), IconButton, FAB (un par écran).
  14. TextField : decoration, onChanged, controller, obscureText, maxLength, keyboardType ; TextFormField avec validator dans un Form.
  15. Dart : var déduit, final / const, String?, ?., ??, !, late, required, ${}.
