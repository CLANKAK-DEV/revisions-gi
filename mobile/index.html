Le code à lancer chez vous

Le dossier exemples_flutter (à côté de ce site, dans le dossier mobile) contient toutes les applications. Une fois : flutter create . dans ce dossier, puis par exemple flutter run -t lib/main_bibliotheque.dart. Les autres points d'entrée : lib/main_imc.dart et lib/main_examen.dart. Les tests se lancent avec flutter test.

Ce que je ne sais pas, et ce que j'ai repéré

  • Je n'ai pas le sujet de votre test : le sujet de l'examen blanc est construit à partir du cours et du travail à rendre.
  • Les images des couvertures et des plats sont des images de remplacement que j'ai dessinées. Remplacez-les par les vôtres.
  • La maquette du travail à rendre est une image du document Moodle : je l'ai reproduite d'après l'image, sans copier le document.
  • Les slides utilisent primary et onPrimary pour les boutons : ils ne compilent plus avec Flutter 3.41.
  • Le sujet de l'IMC dit « Poids normal » mais son tableau dit « Poids idéal » ; le tableau a un trou entre 39.9 et 40.
  • Pour les exercices du cours dont l'image n'était pas lisible dans le texte, j'ai écrit ma propre solution à partir de la consigne.
