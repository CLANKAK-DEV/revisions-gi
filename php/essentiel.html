Le module en 8 phrases

  1. Un navigateur (client) envoie une requête HTTP, Apache la confie à PHP, qui génère du HTML : le visiteur ne voit jamais le code PHP.
  2. Les scripts se placent dans htdocs et s'ouvrent par http://localhost/..., jamais par double-clic.
  3. Les variables commencent par $, leur type est dynamique ; var_dump montre type et valeur.
  4. Utiliser === plutôt que == ; connaître les valeurs « falsy » ; une chaîne non numérique dans un calcul provoque une TypeError.
  5. Un tableau associe des clés à des valeurs ; foreach, les tris, array_map, array_filter et array_reduce remplacent la plupart des boucles.
  6. Une fonction typée renvoie une valeur avec return et n'affiche rien ; ses variables sont locales ; & passe par référence.
  7. HTTP n'a pas de mémoire : le cookie transporte un identifiant, la session garde les données sur le serveur, les mots de passe sont hachés.
  8. Tout ce qui vient d'un formulaire est suspect : on valide côté serveur, on échappe à l'affichage, on termine par une redirection (PRG), et on contrôle les uploads par le type réel.

Les 15 éléments à connaître par cœur

  1. Client, serveur, requête, réponse : PHP s'exécute sur le serveur, le navigateur reçoit du HTML.
  2. GET lit (URL, favori). POST modifie (corps de la requête). POST ne chiffre pas.
  3. Codes : 200 OK, 301 et 302 redirection, 403 interdit, 404 introuvable, 500 erreur serveur.
  4. Type dynamique ; isset est false si null ; empty est true pour "", "0", 0, null, false, [].
  5. Chaîne dans un calcul : numérique, ça passe ; « 10 pommes », Warning ; « abc », TypeError.
  6. == convertit, === compare type et valeur. Guillemets doubles interpolent, simples non.
  7. switch compare en souple avec break ; match est strict, renvoie une valeur, lève UnhandledMatchError.
  8. for (tours connus), while (condition), do ... while (au moins un tour), foreach (tableaux) ; break et continue.
  9. sort renumérote, asort garde les clés ; $t = sort($t) est une erreur.
  10. array_map(fonction, tableau) mais array_filter(tableau, fonction) ; filter garde les clés.
  11. Fonction : paramètres typés, valeur par défaut, return, variables locales, & pour la référence, static pour la mémoire, cas d'arrêt pour la récursivité.
  12. Modes de fopen : r lit, w efface, a ajoute, x exige que le fichier n'existe pas.
  13. Cookie chez le client (modifiable), session sur le serveur (seul l'identifiant circule) ; httponly, samesite ; session_regenerate_id(true) après la connexion.
  14. password_hash (sel automatique, 60 caractères) et password_verify ; jamais en clair, jamais MD5.
  15. Validation côté serveur, filter_var testé avec === false, échappement à l'affichage, PRG avec header + exit, upload : taille, type réel, nom aléatoire.
