Chapitre 1 : introduction à PHP

Le Web et l'architecture client-serveur Priorité 2

Définition : architecture client-serveur

Deux programmes communiquent : le client envoie des requêtes, le serveur les attend, les traite et renvoie une réponse. Sur le Web, le client est le navigateur, le serveur est Apache ou Nginx.

  • Le client prend l'initiative ; le serveur tourne en permanence et écoute un port (80 pour HTTP, 443 pour HTTPS).
  • HTTP définit le format des messages : la requête contient une méthode (GET, POST), une URL, des en-têtes ; la réponse contient un code de statut, des en-têtes et un contenu (souvent du HTML). HTTPS est la version chiffrée.
  • Une URL se compose d'un protocole, d'un domaine, éventuellement d'un port, d'un chemin et de paramètres : https://www.epa.ma:443/etudiants/liste.php?annee=4. localhost désigne la machine elle-même (127.0.0.1).

Statique ou dynamique ? Un site statique envoie des fichiers HTML écrits à l'avance, identiques pour tous. Un site dynamique construit la page à la demande avec un programme serveur (PHP), éventuellement une base de données. Le navigateur ne reçoit que du HTML : il ne voit jamais le code PHP.

Le langage PHP Priorité 3

Définition : PHP

« PHP: Hypertext Preprocessor » : langage libre, interprété, de script côté serveur, intégrable au HTML. Le script est exécuté par l'interpréteur sur le serveur ; le résultat (en général du HTML) est envoyé au navigateur.

  • Gratuit, multiplateforme, typage dynamique (types déclarables depuis PHP 7), multi-paradigme (procédural et objet), écosystème riche (Composer, Laravel, Symfony).
  • Repères : 1994 Rasmus Lerdorf ; PHP 5 (2004) objet et PDO ; PHP 7 (2015) performances et types ; PHP 8 (2020) JIT, match, arguments nommés.
  • Exemples : WordPress (plus de 40 % des sites), Wikipédia, Laravel, Magento, PrestaShop.

L'environnement de développement Priorité 2

  • Il faut un serveur web, l'interpréteur PHP, une base de données (MySQL ou MariaDB) et un éditeur. XAMPP regroupe Apache, MariaDB, PHP et phpMyAdmin.
  • Les scripts se placent dans htdocs (C:\xampp\htdocs) et s'ouvrent à http://localhost/.... Pour le service : Apache sert PHP (port 80), MySQL sert la base (port 3306, utile à partir du chapitre 7).
  • Si Apache refuse de démarrer, le port 80 est presque toujours déjà utilisé : changer Listen 8080 dans httpd.conf.
  • phpinfo() vérifie l'installation (version, php.ini, extensions). Ne jamais le laisser en production.
  • Serveur intégré pour le développement : php -S localhost:8000.

L'erreur la plus fréquente

Ouvrir un fichier PHP par double-clic : l'adresse commence par file:///, le fichier est lu sur le disque sans Apache ni PHP, donc le code n'est pas exécuté. Toujours démarrer Apache puis ouvrir http://localhost/....

Syntaxe de base Priorité 1

  • Le code PHP est entre <?php et ?>. Chaque instruction se termine par ;. La balise de fermeture est facultative (même conseillée de l'omettre) en fin de fichier 100 % PHP. <?= $nom ?> est un raccourci pour <?php echo $nom; ?>.
  • echo affiche (plusieurs arguments possibles), print n'en accepte qu'un.
  • Commentaires : // et # sur une ligne, /* ... */ sur plusieurs lignes.

Définition : variable

Un emplacement mémoire nommé qui stocke une valeur. Le nom commence par $, puis une lettre ou _, puis lettres, chiffres ou _. Sensible à la casse : $nom et $Nom sont deux variables.

Le typage est dynamique : le type vient de la valeur. var_dump() affiche le type et la valeur, c'est l'outil de débogage de base.

Chaînes et calculs

  • Guillemets doubles : interpolation des variables et des séquences comme \n. Guillemets simples : texte pris tel quel. Concaténation : . ; ajout : .=.
  • Une chaîne dans un calcul (PHP 8) : numérique ("10") convertie sans erreur ; commence par un nombre ("10 pommes") : le nombre est utilisé avec un Warning ; non numérique ("abc", "") : TypeError, le script s'arrête.
  • "5" + 5 vaut l'entier 10, alors que "5" . 5 vaut la chaîne "55".

Définition : constante

Un identificateur dont la valeur ne change plus pendant l'exécution. Sans $, en majuscules par convention : const TVA = 0.20; ou define('ECOLE', 'EPA');. Prédéfinies : PHP_VERSION, PHP_EOL, __DIR__, __FILE__, __LINE__.

Comparaison souple et stricte

== convertit les types avant de comparer : 1 == "1" est vrai, null == false est vrai, "1e3" == "1000" est vrai. === compare la valeur et le type : 1 === "1" est faux. Règle : utiliser === et !== par défaut.

Valeurs « falsy » (considérées comme fausses) : false, 0, 0.0, "", "0", [], null. Tout le reste est vrai.

Court-circuit : dans A && B, si A est faux, B n'est pas évalué ; dans A || B, si A est vrai, B n'est pas évalué.

Chapitre 3 : tableaux et fonctions

Les tableaux Priorité 1

Définition : tableau (array)

Une collection ordonnée de paires clé et valeur dans une seule variable. Les clés sont des entiers ou des chaînes, les valeurs peuvent être de n'importe quel type, y compris d'autres tableaux.

  • Indexé : clés entières à partir de 0. $t = ["Agadir", "Rabat"]; echo $t[0];
  • Associatif : clés textuelles. $e = ["nom" => "Benali", "age" => 21]; ; isset($e["tel"]) teste existence et non null, array_key_exists teste seulement la clé.
  • Multidimensionnel : $promo[1]["nom"]. C'est la forme d'un résultat de requête SQL : liste d'enregistrements.
  • Ajouter : $t[] = 40; ; supprimer : unset($t[1]) (laisse un trou, array_values renumérote) ; taille : count($t) ; afficher pour déboguer : print_r ou var_dump dans <pre>.

Ces fonctions modifient le tableau par référence et renvoient true. Écrire $t = sort($t); fait de $t un booléen : le tableau est perdu.

Piège : l'ordre des arguments

Pour array_map, la fonction vient d'abord ; pour array_filter et array_reduce, le tableau vient d'abord.

$prixHT = [100, 250, 40, 800];
$ttc   = array_map(fn($p) => $p * 1.2, $prixHT);            // [120, 300, 48, 960]
$chers = array_filter($prixHT, fn($p) => $p > 200);          // [1 => 250, 3 => 800] (clés gardées)
$total = array_reduce($prixHT, fn($acc, $p) => $acc + $p, 0); // 1190

Les fonctions Priorité 1

Définition : fonction

Un bloc d'instructions nommé qui réalise une tâche et qu'on appelle autant de fois que nécessaire. Elle reçoit des paramètres et renvoie une valeur de retour avec return. Une fonction sans return renvoie null.

function prixTTC(float $prixHT, float $tva = 0.20): float
{
    return $prixHT * (1 + $tva);
}
prixTTC(100);                       // 120
prixTTC(100, 0.10);                 // 110
prixTTC(tva: 0.07, prixHT: 50);     // 53.5 (arguments nommés, PHP 8)
  • Paramètre : la variable de la définition. Argument : la valeur passée à l'appel. Les paramètres avec valeur par défaut se placent en dernier.
  • Types : int, float, string, bool, array ; nullable ?float ; union int|float ; void. declare(strict_types=1); en première ligne interdit les conversions automatiques ("5" passé à un int donne une TypeError).
  • Portée : une variable définie dans une fonction est locale ; une globale n'est pas visible dans les fonctions. On passe les données en paramètres (global est déconseillé). static garde la valeur d'un appel à l'autre.
  • Valeur ou référence : par défaut une copie ; avec & (int &$n) la fonction modifie la variable d'origine.
  • Anonyme et fléchée : function ($x) use ($taux) { ... } importe $taux ; fn($x) => $x * $taux la capture automatiquement. Servent de callbacks.
  • Récursive : une fonction qui s'appelle elle-même, avec obligatoirement un cas d'arrêt. Exemple : factorielle, parcours d'un menu à plusieurs niveaux.

Bonnes pratiques

Un nom, une action (calculerMoyenne, estAdmis). Une fonction, une responsabilité. Fonctions courtes. Séparer le calcul (qui fait return) de l'affichage (qui fait echo). Typer les paramètres et le retour.

HTTP sans état, cookies et sessions Priorité 1

Protocole sans état

Chaque requête HTTP est traitée indépendamment : le serveur ne se souvient de rien après la réponse. Pour reconnaître un utilisateur, le navigateur doit renvoyer un identifiant à chaque requête : c'est le rôle des cookies.

Définition : cookie

Petite donnée texte (nom et valeur, environ 4 Ko) que le serveur demande au navigateur de garder, via l'en-tête Set-Cookie. Le navigateur la renvoie au même site à chaque requête jusqu'à expiration. Stocké chez le client, lisible et modifiable par l'utilisateur : jamais de donnée sensible.

setcookie('theme', 'sombre', [
    'expires'  => time() + 30*24*3600,   // sans expires : disparaît à la fermeture du navigateur
    'path'     => '/',
    'httponly' => true,                  // inaccessible au JavaScript (protège contre le vol par XSS)
    'samesite' => 'Lax',                 // limite l'envoi depuis d'autres sites (protection CSRF)
]);
$theme = $_COOKIE['theme'] ?? 'clair';   // lire
setcookie('theme', '', time() - 3600, '/'); // supprimer : date passée

setcookie() s'appelle avant tout affichage (c'est un en-tête HTTP). Un cookie créé n'apparaît dans $_COOKIE qu'à la requête suivante.

Définition : session

Un mécanisme qui conserve côté serveur des données propres à un visiteur. PHP génère un identifiant aléatoire, l'envoie dans un cookie (PHPSESSID) et retrouve les données à chaque requête grâce à lui. Elles sont dans $_SESSION. Seul l'identifiant circule.

CookieSession
Stocké chez le clientStockée sur le serveur

Peut survivre à la fermeture du navigateurExpire après inactivité ou déconnexion

Préférences, langue, « se souvenir de moi »Authentification, panier, droits
  • session_start(); au début de chaque page concernée, avant tout affichage. Déconnexion en trois étapes : $_SESSION = []; puis session_destroy(); puis suppression du cookie de session.
  • Sécuriser : session_regenerate_id(true) après la connexion (contre la fixation de session) ; options httponly, secure, samesite ; limiter l'inactivité ; HTTPS en production.

Mots de passe Priorité 1

Fonction de hachage

Transforme une donnée en empreinte de longueur fixe, à sens unique. On ne déchiffre pas : on calcule l'empreinte du mot de passe saisi et on la compare à celle stockée. Le sel aléatoire rend deux empreintes différentes pour un même mot de passe. bcrypt et Argon2 sont lents volontairement ; MD5 et SHA-1 sont à proscrire.

$hash = password_hash($mdp, PASSWORD_DEFAULT);        // 60 caractères, sel automatique
if (password_verify($saisi, $hash)) {
    session_regenerate_id(true);
    $_SESSION['user'] = $email;
} else {
    echo "Identifiants incorrects";                      // message volontairement vague
}

Chapitre 5 : formulaires et upload

Formulaires, GET et POST Priorité 1

Définition : formulaire

Un élément <form> qui regroupe des champs et un bouton. À l'envoi, le navigateur envoie une requête HTTP avec les valeurs, chacune identifiée par l'attribut name. action donne le script cible, method la méthode (GET ou POST).

Superglobales

Tableaux associatifs prédéfinis, remplis à chaque requête et accessibles partout, même dans les fonctions : $_GET (paramètres de l'URL), $_POST (corps de la requête), $_SERVER (infos de requête), $_FILES, $_COOKIE, $_SESSION.

POST ne chiffre pas

POST évite seulement d'afficher les données dans l'URL et l'historique. Sans HTTPS, elles circulent en clair.

  • Toutes les valeurs reçues sont des chaînes. On lit avec une valeur par défaut : $q = $_GET['q'] ?? '';. On nettoie avec trim(), on convertit avec (int).
  • Un même script affiche et traite : if ($_SERVER['REQUEST_METHOD'] === 'POST') { ... }.
  • Les valeurs de $_SERVER['HTTP_*'] viennent du navigateur et se falsifient.

Valider les données Priorité 1

Validation et filtrage

Valider : vérifier qu'une donnée respecte les règles (présence, format, longueur, valeur autorisée) et la refuser sinon. Filtrer : la transformer pour la rendre conforme (espaces, type, minuscules). Toujours côté serveur : la validation HTML5 (required, type="email") améliore le confort mais se contourne.

Post / Redirect / Get et message flash Priorité 1

Motif PRG

Après le traitement réussi d'un POST, ne pas afficher directement le résultat : rediriger (réponse 302) vers une page demandée en GET. Recharger cette page refait un simple GET, donc pas de double inscription ni de double commande. Écrire header('Location: page.php'); exit;. Le exit est obligatoire, sinon le script continue ; header() s'appelle avant tout affichage.

Message flash : message mis en session juste avant la redirection, affiché une seule fois par la page suivante, puis supprimé (unset). Les variables du script précédent ont disparu, la session est le seul pont.

// inscription.php, après succès
$_SESSION['flash'] = 'Inscription réussie !';
header('Location: merci.php'); exit;

// merci.php
if (isset($_SESSION['flash'])) { echo e($_SESSION['flash']); unset($_SESSION['flash']); }

  • Formulaire : méthode POST, enctype="multipart/form-data" (sans lui le fichier n'est pas transmis), champ <input type="file">. PHP reçoit le fichier dans un dossier temporaire et le décrit dans $_FILES (name, type, tmp_name, error, size).
  • name et type viennent du navigateur : falsifiables. Un pirate peut envoyer shell.php présenté comme une image, puis l'exécuter en ouvrant /uploads/shell.php.
