Pièges et aide-mémoire

Les erreurs qui font perdre des points, celles des TP, et une méthode pour répondre aux « Prédire l'affichage ». Chaque règle a été vérifiée en exécutant du code.

Pièges de cours

1. Ouvrir un fichier PHP par double-clic

L'adresse commence par file:/// : ni Apache ni PHP n'interviennent, le code s'affiche. Toujours http://localhost/... avec Apache démarré.

2. Penser que le visiteur voit le PHP

Il ne reçoit que le HTML produit. Ctrl + U ne montre aucun code PHP, mais montre les commentaires HTML.

3. Les noms de variables sont sensibles à la casse

$Prenom et $prenom sont deux variables : la première non définie donne un Warning. Les noms de fonctions ne le sont pas, les variables oui.

4. isset et empty

isset($x) est false si $x vaut null. empty($x) est true pour 0 et "0" : une note de 0 est « vide ». Ni l'un ni l'autre ne provoque d'avertissement.

5. Le type dépend de la valeur, pas de la variable

"14.5" est une chaîne numérique : is_numeric dit true, get_debug_type dit « string ».

6. + n'est pas .

"5" + 5 donne l'entier 10, "5" . 5 donne la chaîne "55". Quand on mélange les deux, mettez des parenthèses : en PHP 8, "Remise : " . 10 + 5 calcule d'abord 10 + 5 et affiche « Remise : 15 ».

7. Cookie et session

Le cookie est chez le client et modifiable : jamais de donnée de sécurité dedans. La session est sur le serveur. Le cookie de session sans expires disparaît à la fermeture du navigateur, donc la session aussi.

8. Validation côté client seulement

required et type="email" se retirent avec l'inspecteur. Sans validation PHP, le formulaire n'est pas protégé.

9. Faire confiance à $_FILES

name et type viennent du navigateur. Le type réel se lit dans le contenu avec finfo.

Pièges de TP

  • Affichage de $moyenne : dans le TP1, l'opérateur / donne un float ; une note de 21 n'existe pas, donc la moyenne visée est inatteignable.
  • TP2 : pour les mentions, match (true) ou if / elseif : un switch classique ne teste pas d'intervalles. Pour la factorielle de 0, 0! = 1.
  • TP3 : ajouterAuPanier prend le panier et le stock par référence, sinon le stock ne baisse jamais. usort sur une copie si l'on veut garder l'ordre d'origine.
  • TP4 : lire l'ancienne date du cookie avant setcookie(). Message flash : ne pas détruire la session avant de le poser. Valider un cookie avec une liste blanche.
  • TP4, connexion : toute sortie (echo) avant session_regenerate_id() provoque un avertissement : préparer le message, traiter, puis afficher.
  • TP5 : le message flash se lit puis s'efface. Une case non cochée est absente de $_POST. Pour un upload, tester aussi UPLOAD_ERR_INI_SIZE : au-delà de upload_max_filesize (2M par défaut), le code d'erreur n'est plus UPLOAD_ERR_OK et le script ne reçoit pas le fichier.

Méthode : « Prédire l'affichage »

  1. Lisez le code ligne par ligne, comme PHP, en notant la valeur de chaque variable sur papier.
  2. Repérez les pièges : guillemets simples ou doubles, + ou ., == ou ===, ++$i ou $i++, break oublié.
  3. Pour un tableau, notez les clés (conservées après array_filter, renumérotées après sort).
  4. Pour une erreur, précisez si elle arrête le script (Parse error, TypeError) ou non (Warning).
  5. Écrivez le type avec la valeur quand on vous demande var_dump : int(15), string(3) "105".

Différences entre versions de PHP à connaître

  • PHP 8 : "abc" + 1 lève une TypeError (PHP 7 : Warning et résultat 1) ; 0 == "a" est false ; match, arguments nommés, str_starts_with existent.
  • PHP 8.4 : fputcsv et fgetcsv demandent le paramètre escape pour éviter une dépréciation.
  • Votre cours cible PHP 8.2 (XAMPP 8.2.12). En cas de doute à l'examen, suivez le cours.
