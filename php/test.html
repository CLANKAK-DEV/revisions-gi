Un test de PHP en 24 questions à choix multiple (plus une question sans numéro), avec la bonne réponse, ce que PHP affiche vraiment, l'explication et la notion à retenir. Répondez d'abord sur papier, puis ouvrez la correction.

Ce que j'ai reçu, et ce que j'ai vérifié

  • Le texte collé contient 24 questions numérotées de 1 à 30 : les numéros 13, 18, 25, 26, 28 et 29 manquent. Je n'ai pas inventé les questions absentes.
  • À la question 30, le tableau a disparu du texte ($t =;). Les quatre réponses ne contiennent que 3, 7 et 10 : j'ai testé les six ordres possibles du tableau, la réponse est toujours la même.
  • Le texte se termine par un extrait sur $_SESSION["flash"] sans numéro, sans énoncé et sans options. Je lui ai donné sa réponse en fin de page.
  • Le texte collé ne contenait pas les réponses. Chaque extrait a été exécuté avec PHP 8.0 (XAMPP) et PHP 8.5 et donne le même résultat : les réponses viennent de l'exécution, pas d'un raisonnement seul.

Les questions

Question 1

Qu'affiche ce code ?

$v = filter_var("0", FILTER_VALIDATE_INT);
echo !$v ? "A" : "B";
echo $v === false ? "C" : "D";
  1. AD
  2. BD
  3. BC
  4. AC
Correction

Réponse : a. AD

Affichage obtenu avec PHP

AD

filter_var("0", FILTER_VALIDATE_INT) renvoie l'entier 0 : la valeur est valide. Comme 0 est « falsy », !$v est vrai : on affiche A. Mais 0 === false est faux (types différents) : on affiche D.

À retenir

C'est exactement pourquoi on teste === false et non !$v : 0 est un entier valide.

Notion : filter_var et === false. À revoir : Chapitre 5.

Question 4

Réponse : a. bool(true) bool(false)

Notion : is_numeric et is_int. À revoir : Chapitre 1.

Question 5

Qu'affiche ce code ?

$total = 10;
function ajouter($n) {
    $total = $n + 1;
    return $total;
}
echo ajouter(5) + $total;
  1. 12
  2. 16
  3. 21
  4. 6
Correction

Réponse : b. 16

Affichage obtenu avec PHP

16

Le $total de la fonction est une variable locale : ajouter(5) renvoie 6 et ne touche pas au $total global (10). Résultat : 6 + 10 = 16.

À retenir

Une fonction ne voit pas les variables globales, et ne les modifie pas non plus.

Notion : portée d'une variable. À revoir : Chapitre 3.

Réponse : c. float(15.5)

Question 7

  3. Sara

Correction

Réponse : d. Sara, Omar

Affichage obtenu avec PHP

array_filter garde les notes d'au moins 10 en conservant les clés : Sara et Omar. array_keys donne les noms, implode les relie par « , ».

Les clés sont conservées : on obtient les noms avec array_keys, pas les notes.

Notion : array_filter, array_keys, implode. À revoir : Chapitre 3.

Question 10

Le fichier inc/auth.php contient require __DIR__ . '/config.php';. Ce fichier est inclus depuis index.php, situé à la racine du site. Quel fichier est chargé ?

// inc/auth.php
require __DIR__ . '/config.php';
  1. config.php à la racine du site
  2. inc/config.php
  3. Aucun : __DIR__ ne fonctionne pas dans un fichier inclus
  4. inc/inc/config.php
Correction

Réponse : b. inc/config.php

__DIR__ est le dossier du fichier qui contient l'instruction, c'est-à-dire inc. Le fichier chargé est donc inc/config.php. Vérifié : avec __DIR__ on charge inc/config.php ; avec un simple require 'config.php', PHP trouve celui de la racine.

À retenir

Sans __DIR__, le chemin relatif est lu depuis le premier script appelé, pas depuis le fichier courant.

Notion : __DIR__ et chemins d'inclusion. À revoir : Chapitre 4.

Question 14

Quelle affirmation décrit un site dynamique ?

  1. Il ne fonctionne qu'avec une connexion HTTPS
  2. Ses pages contiennent des animations CSS ou JavaScript
  3. Ses pages sont produites par le serveur à chaque requête, par exemple à partir d'une base de données
  4. Ses pages HTML sont écrites à l'avance et envoyées telles quelles
Correction

Réponse : c. Ses pages sont produites par le serveur à chaque requête, par exemple à partir d'une base de données

Un site dynamique construit ses pages sur le serveur au moment de la demande (programme PHP, base de données). La dernière réponse décrit un site statique.

À retenir

Dynamique ne veut pas dire « animé » : ce mot concerne le serveur, pas les animations.

Notion : site statique et site dynamique. À revoir : Chapitre 1.

Question 22

Lorsqu'un navigateur demande http://localhost/tp1/index.php, qui transmet le fichier index.php à l'interpréteur PHP ?

  1. Le serveur web Apache
  2. Le navigateur
  3. Le système d'exploitation du client
  4. Le serveur MySQL
Correction

Réponse : a. Le serveur web Apache

Le navigateur envoie la requête ; Apache trouve le fichier dans htdocs et, voyant l'extension .php, le confie à l'interpréteur PHP. Le navigateur ne reçoit que le HTML produit.

Question 23

Le fichier inclus n'existe pas. Quelle est la différence entre include et require ?

include "absent.php";   // ou require "absent.php";
echo "suite";
  1. require provoque une erreur fatale et arrête le script ; include affiche un avertissement et continue
  2. Les deux arrêtent le script
  3. include provoque une erreur fatale ; require affiche un avertissement et continue
  4. Aucune : les deux ignorent le fichier manquant
Correction

Réponse : a. require provoque une erreur fatale et arrête le script ; include affiche un avertissement et continue

include : avertissement (Warning), le script continue. require : erreur fatale, le script s'arrête. Vérifié : avec include la ligne suivante s'exécute, avec require elle n'est jamais atteinte.

À retenir

Le mot « require » dit « indispensable » : sans le fichier, on s'arrête.

Notion : include et require. À revoir : Chapitre 1.

Question 30

  4. 3,7,10

Réponse : b. 10,7,3

La question sans numéro : le message flash

Question sans énoncé

Le texte se termine par ce code, sans question ni options. La question est probablement : « Qu'affiche ce code ? »

session_start();
$_SESSION["flash"] = "OK";
echo $_SESSION["flash"] ?? "";
unset($_SESSION["flash"]);
echo $_SESSION["flash"] ?? "vide";
Correction

Réponse : OKvide

Affichage obtenu avec PHP

OKvide

session_start() ouvre la session. On range « OK » dans $_SESSION["flash"] et on l'affiche : OK. Puis unset supprime la clé : le second echo utilise ??, qui donne la valeur par défaut « vide » quand la clé n'existe plus. C'est le principe du message flash : affiché une seule fois, puis supprimé.

À retenir

session_start() doit être appelé avant tout affichage. Lire une clé supprimée sans ?? provoque un avertissement « Undefined array key ».

Notion : session et message flash. À revoir : Chapitre 4 et chapitre 5.
